# Community knowledge base

Curated advice from the Nebulous: Fleet Command community Discord.
Design: `docs/superpowers/specs/2026-07-13-community-knowledge-base-design.md`.

- `raw/` — raw thread dumps from `scripts/export_thread.py` (committed provenance)
- `entries/` — **canonical** curated entries, one TOML file per category
- `tags.toml` — controlled tag vocabulary (validated by tests)
- `exports/` — generated by `scripts/export_knowledge.py` (gitignored)
- `QUESTIONS.md` — open questions from curation awaiting human review

## Adding knowledge from a new thread/channel

1. `python scripts/export_thread.py <channel_or_thread_id>`
2. Run the `curate-advice` skill in a Claude Code session over the new raw dump
3. Review the git diff of `entries/` and `QUESTIONS.md`, then commit
4. `python scripts/export_knowledge.py` to refresh mod/wiki artifacts
