# `!ng modded` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `modded` flag to `!nextgame`/`!ng` so players can be pinged only when a server running mods next becomes ready.

**Architecture:** Mirror the existing `ptb_only` filter with a parallel `modded_only` boolean threaded through detection (SteamAPI), the waiter store + matching (ServerMonitor), and the command (runbot.py). A server is "modded" when its rules advertise a non-empty `modList`. Detection and matching are covered by unit tests; the Discord command layer is verified manually.

**Tech Stack:** Python 3.11, Django (ORM/app registry only), discord.py, python-valve (server rules), pytest.

**Branch:** `feature/ng-modded` (already created; region fix is its base commit).

---

## Context for the implementer

- The waiter store is `ServerMonitor.next_game_waiters`, a dict keyed today by `(user_id, ptb_only)`. This plan extends the key to `(user_id, ptb_only, modded_only)`. Several sites unpack the 2-tuple as `(user_id, _)` — they must switch to index access.
- "Ready" servers (the trigger) are unchanged: a lobby with `3 <= players < map_capacity`, or a server in/just-entering `debrief`. `modded_only` only *narrows* that set.
- Server rule dicts reach `_create_enhanced_server_data` via two paths: `_parse_nebulous_rules_json` (keys keep original case, e.g. `modList`) and `_extract_direct_nebulous_rules` (keys lowercased). Detection must tolerate both, hence checking `modList` and `modlist`.
- Verified live: MFC servers report a non-empty `modList`; ERI (vanilla) servers report none.

    def _rules_indicate_modded(rules: Optional[Dict]) -> bool:

```python
    def find_matching_servers_for_notification(self, ptb_only: bool = False, modded_only: bool = False) -> List[Dict]:
        """
        Find servers that match the notification criteria:
        - Lobby servers with 3+ players but less than max capacity
        - Servers in debrief status
        - If ptb_only=True, only PTB (test branch) servers
        - If modded_only=True, only servers running mods (non-empty modList)
        Returns list of matching servers.
        """
        trigger_servers = []

        # Check for joinable lobby servers with 3+ players
        for server in self.cached_servers:
            if server.get('status') == 'lobby':
                players = server.get('players', 0)
                capacity = server.get('map_capacity', 8)
                if players >= 3 and players < capacity:
                    if self._server_matches_mode(server, ptb_only, modded_only):
                        trigger_servers.append(server)

        # Check for servers in debrief
        for server in self.cached_servers:
            if server.get('status') == 'debrief':
                if self._server_matches_mode(server, ptb_only, modded_only):
                    if server not in trigger_servers:
                        trigger_servers.append(server)

        # Also check recent debrief transitions
        for _server_id, server in self.recent_debrief_transitions.items():
            if self._server_matches_mode(server, ptb_only, modded_only):
                if server not in trigger_servers:
                    trigger_servers.append(server)

        return trigger_servers
```
