## Future runtime updates

1. Validate the intended commit in an isolated test application with all privileged
   intents off. Keep production credentials/database out of the test instance.
2. Record the exact image and checksum. Retain the running intent-off image,
   private Compose/environment settings, command tree and an integrity-checked
   online database backup. Verify recovery using a separate restored copy.
3. Deploy the verified image, preserving mounts/ports and explicit intent-off
   configuration. Recreate the container for environment changes; do not rebuild
   on the small VM or re-enable privileged intents as a routine deployment step.
4. If the command schema changed, deliberately sync the authorized application
   using the guarded owner operation. Never sync on startup/reconnect, and verify
   global registrations without guild copies masking them.
5. Verify a fresh gateway identification, HTTP health, monitoring, actual commands,
   persistence and edits beyond interaction-token expiry. Investigate OOMs,
   restart loops, blocked heartbeats and sustained swap pressure before closing.
6. Keep announcements separate: use the exact approved copy/channel/timing only.
   No automatic broadcast, test-channel preview, unsolicited mention or DM.

Documentation-only updates do not require a container restart or command sync.
Branch publication permission alone does not authorize future production changes.

## Recovery

Do not roll back to 2.9.1 after cutoff: it requests Message Content. Repair forward
or use a verified intent-off image. Do not restore the database for an application
failure; that would discard newer statistics/advice. Data recovery needs a
separate decision about the actual fault and potential data loss.

A failed announcement does not justify reverting working software. Inspect the
destination before retrying an uncertain post; send only unsent approved messages.

User guide: `/guide` inside Discord. Review copy is in
[the announcement drafts](2.10.0-user-messages.md); it contains no external guide link.
