# Game Persistence Design

## Overview

The statistics system now properly tracks games with persistent storage and unique IDs. Games are **saved to the database immediately when they start** and can be recovered across bot restarts.

## Key Features

### ✅ Unique Game IDs
- Every game gets a unique ID (auto-incremented primary key)
- Access via `game.id` or `game.pk`
- IDs persist across bot restarts

### ✅ Immediate Database Storage
- Games are saved to database the **instant** they start (lobby → in_game transition)
- No data loss if bot crashes during a game
- Database is the source of truth, not in-memory state

### ✅ Game Recovery on Restart
- On bot startup, all ongoing games are loaded from database
- Tracking continues seamlessly where it left off
- Logs show: `"Recovered X ongoing game(s) from database"`

### ✅ Proper Game Lifecycle Tracking

```
lobby → in_game → debrief → lobby
         ↓          ↓         ↓
      CREATE     UPDATE    FINALIZE
      (save)     (end)     (complete)
```

## Database Schema

### GameSession Model

```python
class GameSession(models.Model):
    # Unique ID (auto-generated by Django)
    id = AutoField(primary_key=True)  # Unique game identifier
    
    # Server info
    server_id = CharField(max_length=255)
    server_name = CharField(max_length=255)
    server_address = CharField(max_length=100)
    
    # Game details
    map_name = CharField(max_length=100)
    game_mode = CharField(max_length=100)
    region = CharField(max_length=50)
    
    # Timing
    game_start = DateTimeField()  # When game started (in_game)
    game_end = DateTimeField(null=True)  # When game ended (debrief)
    lobby_start = DateTimeField(null=True)  # Optional lobby tracking
    
    # Player counts
    players_at_start = IntegerField()  # Players when game started
    players_at_end = IntegerField()  # Players when game ended
    max_players_during_game = IntegerField()  # Peak players
    
    # Game attributes
    competitive = BooleanField()
    autobalance = BooleanField()
    rank_restricted = BooleanField()
    
    # Status
    is_ongoing = BooleanField(default=True)  # True until game returns to lobby
    is_valid_game = BooleanField()  # True if duration >= 5 minutes
    duration_seconds = IntegerField(null=True)  # Calculated on end
```

## How It Works

### 1. Game Start (lobby → in_game)
```python
# Server transitions to in_game
game = GameSession.objects.create(
    server_id="server_123",
    server_name="My Server",
    map_name="Hotspot",
    game_start=now(),
    players_at_start=8,
    max_players_during_game=8,
    is_ongoing=True,  # Mark as ongoing
    # ... other fields ...
)
# game.id is now available (e.g., 42)
logger.info(f"Game #{game.id} started")
```

### 2. During Game (in_game)
```python
# Every monitoring cycle, update max players if needed
if current_players > game.max_players_during_game:
    game.max_players_during_game = current_players
    game.save(update_fields=['max_players_during_game', 'updated_at'])
```

### 3. Game Ends (in_game → debrief)
```python
# Server enters debrief
game.game_end = now()
game.players_at_end = current_players
game.save()
logger.info(f"Game #{game.id} entered debrief")
```

### 4. Return to Lobby (debrief → lobby)
```python
# Server returns to lobby, finalize the game
game.is_ongoing = False
game.calculate_duration()  # Sets duration_seconds and is_valid_game
game.save()

if game.is_valid_game:  # >= 5 minutes
    logger.info(f"✅ Game #{game.id} completed: {game.duration_seconds}s")
else:
    logger.info(f"⏱️ Game #{game.id} too short: {game.duration_seconds}s")
```

### 5. Bot Restart Recovery
```python
# On bot startup
ongoing_games = GameSession.objects.filter(is_ongoing=True)
for game in ongoing_games:
    # Resume tracking this game
    active_sessions[game.server_id] = game.id
    
logger.info(f"Recovered {ongoing_games.count()} ongoing game(s)")
```

## Statistics Calculation

Stats are now calculated **directly from the games table**, not from pre-aggregated data:

```python
# Total games played
total_games = GameSession.objects.filter(is_valid_game=True).count()

# Games today
today_start = datetime.now().replace(hour=0, minute=0, second=0)
games_today = GameSession.objects.filter(
    is_valid_game=True,
    game_start__gte=today_start
).count()

# Most played maps
top_maps = GameSession.objects.filter(
    is_valid_game=True
).values('map_name').annotate(
    count=Count('id')
).order_by('-count')[:10]

# Server usage
server_stats = GameSession.objects.filter(
    is_valid_game=True,
    server_id='server_123'
).aggregate(
    total_games=Count('id'),
    avg_duration=Avg('duration_seconds'),
    total_playtime=Sum('duration_seconds')
)
```

## Benefits

### 🎯 No Data Loss
- Games are saved immediately when they start
- Bot crashes don't lose game data
- Only loses in-progress max player count updates (minor)

### 🔄 Seamless Restarts
- Bot can restart without losing track of ongoing games
- Continues tracking from where it left off
- No duplicate game entries

### 📊 Real-Time Statistics
- Stats calculated from actual game data
- No stale cached statistics
- Always accurate

### 🔍 Full Audit Trail
- Every game has a unique ID for tracking
- Can look up any specific game: `GameSession.objects.get(id=42)`
- Complete history of all games played

### 🚀 Scalable
- Indexed queries for fast lookups
- Can handle thousands of games
- Efficient filtering by date, server, map, etc.

## Querying Games

### Get a specific game
```python
game = GameSession.objects.get(id=42)
print(f"Game {game.id}: {game.map_name} on {game.server_name}")
print(f"Duration: {game.duration_seconds}s with {game.players_at_start} players")
```

### Get all games on a server
```python
server_games = GameSession.objects.filter(
    server_id='server_123',
    is_valid_game=True
).order_by('-game_start')
```

### Get ongoing games
```python
ongoing = GameSession.objects.filter(is_ongoing=True)
print(f"Currently {ongoing.count()} games in progress")
```

### Get games by date range
```python
from datetime import datetime, timedelta
week_ago = datetime.now() - timedelta(days=7)
recent_games = GameSession.objects.filter(
    game_start__gte=week_ago,
    is_valid_game=True
)
```

## Migration Path

The system includes a migration that adds the `is_ongoing` field to existing games:

```bash
python manage.py migrate nebulous_bot 0003_add_is_ongoing_field
```

Existing completed games get `is_ongoing=False` automatically.

## Testing

To test game persistence:

1. Start a game on a server (wait for it to transition to in_game)
2. Note the game ID from logs: `"Game #X started"`
3. Restart the bot
4. Check logs for: `"Recovered 1 ongoing game(s) from database"`
5. Let the game end (return to lobby)
6. Verify completion log: `"Game #X completed"`

The game should be tracked continuously with the same ID across the restart.
